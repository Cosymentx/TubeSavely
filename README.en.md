## ✨ Features

### 🌍 Extensive Platform Support — All in One
Proudly supports **1800+ mainstream and niche video platforms** worldwide, including YouTube, Instagram, TikTok, Bilibili, Vimeo, and many more. No matter where you find great content, TubeSavely is your exclusive bridge — one-click download.

### 🎬 High Definition, Your Choice
Multiple resolutions from standard to ultra-high definition. Every frame you download is crisp and smooth, whether on mobile or a large desktop screen.

### ⚡ High-Speed Downloading
Advanced multi-threaded downloading technology. Even massive video files are completed in no time. Say goodbye to long waits.

### 🎞 Video Convert & Compress
Built-in FFmpeg engine — convert between formats (MP4 / MKV / MOV / AVI / WEBM / MP3 and more) and compress videos with multiple presets. Native desktop UI for a seamless experience.

### 🖥️ Cross-Platform
- **Desktop**: Windows, macOS, Linux — native desktop layout
- **Mobile**: iOS, Android
- **Web**: [TubeSavely-Vue](https://github.com/Cosymentx/TubeSavely-Vue) — browser-based

### 🔒 Safe & Compliant
Strictly adheres to each platform's terms of use. No personal data is stored or transmitted.

## 🚀 Getting Started

### Prerequisites
- Flutter 3.x (run `flutter doctor` to verify)
- Xcode 14+ for macOS/iOS builds

### Run Locally
```bash
# Clone the repo
git clone https://github.com/Cosymentx/TubeSavely.git
cd TubeSavely

# Install dependencies
flutter pub get

# Run on macOS
flutter run -d macos

# Run on iOS
flutter run -d ios

# Run on Android
flutter run -d android
```
